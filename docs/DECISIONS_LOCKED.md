# Locked Design Decisions

These decisions supersede older brainstorming if any conflict appears elsewhere.

1. Hero is on top of the central tower.
2. Enemies approach from all directions; no fixed lane requirement.
3. No manual movement in the core game.
4. One run uses exactly one hero/class. No mid-run class rotation.
5. Start with Archer; Warrior and Mage are introduced later through campaign progression. Rogue is retained but pushed later (~Lv22–25) and uses crit/attack-speed/bleed/poison rather than target-priority micro.
6. Any campaign stage should be beatable by any unlocked appropriately progressed class.
7. First 20 campaign levels collectively function as onboarding.
8. The Almanac is a large obvious book and a detailed in-game wiki. It is accessible during upgrade choice and from normal menus/pause.
9. Environmental mechanics vary by location and gradually enter onboarding.
10. Endless is pseudo-infinite, not dependent on weekly seasonal events.
11. Endless reward growth stops around 40 minutes; difficulty keeps scaling until the run becomes practically impossible.
12. Endless upgrade trees remain open to multiple branches. Started unfinished branches are guaranteed representation in upgrade choices; new branches retain a chance to appear.
13. Super Nodes combine developed branches, are visually special and are capped (initial target: max 4; Apex may consume 2 slots).
14. Permanent progression and run build power are separate; a good in-run build must matter greatly.
15. No hard paywall, no mandatory ad interruptions during active combat.
16. Browser/GitHub Pages is the development/staging target; Yandex Games is a production platform adapter.
17. Visual style is the approved moderately pixelized fantasy style in `assets/references/style_reference_approved.png` and the core asset sheets.
